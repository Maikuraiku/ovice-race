# oVice Racing

oVice のカスタムオブジェクト（拡張オブジェクト）で遊べる、トップビューのオンライン対戦レースゲームです。

- **パーティー制**：1 人が「パーティーを作る」→ 4 文字のコードを伝える → ほかの人はコードを入力して参加 → ホストが「レース開始」。oVice の近くにいる人の画面には「○○ のパーティー」の参加ボタンも表示されます。
- **自前のサーバー不要**：静的ファイルだけで動きます。参加者同士はブラウザ間で直接通信します（接続相手を見つける部分だけ PeerJS の無料公開サーバーを使います）。
- oVice の名前とアバターがそのまま車に表示されます。
- 待っている間は練習走行 → ホストの合図でパーティー全員がカウントダウン → 周回レース → リザルト。
- 視点は「固定（北が上）」と「追従（車の向きに合わせて回転）」を切り替えられます（画面右下のボタン、または V キー）。

## スピード版（海の上の道路）

別の URL で、スピード重視の版も公開しています：**https://maikuraiku.github.io/ovice-race/speed/**（ファイルは `speed/` フォルダ）

- 道幅がさらに広く（480）、速度も大幅アップ。速いほど集中線が出て、カメラが引きます。
- 1 周約 58,000 の大型コース。右・左の両方向のカーブ、S 字、大きな U ターン（上から食い込む部分）、うねりを組み合わせた形で、どのカーブも最高速のまま曲がれる緩やかさです（一番きついところで半径約 800）。周回数は 1〜3 周（初期値 2 周）。
- 海の上のコンクリート道路。道路の両脇に街灯が並びます。
- 壁や芝生はなく、**道路から落ちると海へ落下 → 1 秒後にその場所の道路中央から再スタート**（1 秒ペナルティ）。
- ロビーの**スピード スライダー**（50〜200%）で速さを調整。パーティーではホストの設定に全員が揃います。
- 右下のボタンで**夜 ⇄ 朝**を切り替え（各自の見た目だけ）。夜は街灯とヘッドライトが光ります。
- かんたんモードでは、ハンドルアシストに加えて、きついカーブの手前で自動的に減速します。

通常版とスピード版のパーティーは別々です（コードを入れても相互には入れません）。oVice にはそれぞれ別のカスタムオブジェクトとして登録できます。

## 3D 版（最高画質）

スピード版と同じルール・コースを、Three.js（WebGL）による本格的な 3D で描く版です：**https://maikuraiku.github.io/ovice-race/3d/**（ファイルは `3d/` フォルダ、描画は `3d/js/render3d.js`）

- 車の後ろから見る 3D カメラ。速くなるほど視野が広がり、カメラが引きます。右下のボタンか V キーで **3D追従 → 上空追従（3D で上空から見下ろし、車の向きに合わせて回る）→ 2D追従（スピード版と同じ真上からの回転する画面）→ 上空固定（北が上）** を切り替えられます。2D追従のあいだは 3D の描画を止めるので軽くなります。
- 空や街灯が映り込む海、橋脚の上を走るコンクリートの高架道路、光る反射板。
- 朝：青空と太陽、影、遠くの街並みと山。夜：星空と月、街灯の光だまり、街の夜景、ヘッドライト、光のにじみ（ブルーム）。
- メタリック塗装の車、ダッシュ時の炎と火の粉、落下時の水しぶき。
- 右下のテーマボタンで **夜 → 朝 → エアロ晴天 → 放課後の夕暮れ → 深夜の蛍光灯** を切り替え（見た目は各自の画面だけ）。後ろの 3 つは、少し懐かしく少しディストピアな Y2K・フルティガーエアロ・リミナルスペース寄りのテーマです（景色は `3d/js/y2k.js`）。
  - 白い曲線の建物が建つ小島、コースを囲むモノレールと無人で走り続ける列車、誰もいない「未来駅」、道路を覆うガラスのアーチ、何も告げない看板。
  - エアロ晴天：鮮やかな青空と入道雲、透き通った海、立ちのぼる泡。放課後の夕暮れ：桃色とラベンダーの空、海面のもや、ナトリウム灯。深夜の蛍光灯：暗い青緑の空、蛍光灯、走査線。
  - ちらつく街灯、フィルムのざらつき・周辺減光・わずかな色ずれ、テーマごとの環境音（WebAudio で合成、🔊 で止められます）。
- 右下の「📷 背景を保存」で、車や表示を消した景色を 4K の PNG 画像で保存できます（保存されない環境では、表示された画像を右クリックして保存）。
- 右下の「画質」で **最高 / 標準 / 軽量** を切り替え（重いと案内が出ます）。WebGL が使えない環境では自動的に 2D 表示になります。

## 操作

| キー | 操作 |
| --- | --- |
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Space | ドリフト |
| V | 視点切り替え（固定 / 追従） |

ロビーの「操作」で難しさを選べます（初期設定は「かんたん」、視点は「追従」）。

- **かんたん**：ハンドルはコースに沿うようアシストされ、壁や芝生に当たっても失速しにくい。
- **ふつう**：アクセル・ハンドルを自分で操作。アシストなしで、最高速が少し速い。

スマホ・タブレットでは画面にボタンが出ます。オレンジのパネルを踏むと加速します。芝生に出ると遅くなります。

## ファイル構成

```
index.html        画面
style.css
js/net.js         oVice との通信（名前・アバターの取得、パーティーの募集表示）
js/party.js       パーティー通信（作成・参加・ホスト経由の中継）
js/track.js       コース形状・当たり判定
js/game.js        物理・同期・描画・UI
dev/serve.js      動作確認用の簡易サーバー（公開には不要）
dev/ovice-mock.html  oVice の親ウィンドウを模したテストページ（公開には不要）
```

## ローカルで試す

```bash
node dev/serve.js
```

- `http://localhost:8123/dev/ovice-mock.html?n=3` … oVice を模したページに 3 人分の画面を並べ（スピード版は `&app=../speed/index.html`）、oVice と同じ通信方式で対戦を確認できます（`&lat=150` で遅延を変更、「＋ 参加者を追加」「退出」で途中参加・退出も試せます）。
- `http://localhost:8123/?name=A` を複数タブで開く … oVice の外で、同じブラウザのタブ同士で対戦。
- URL に `&transport=local` を付けると、インターネットに接続せずにタブ同士でパーティーを試せます。

## 公開（GitHub Pages の例）

oVice に登録する URL は **HTTPS で公開されている必要があります**。

1. GitHub で新しいリポジトリを作り、このフォルダの中身を push する
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

Netlify や Cloudflare Pages など、静的ファイルを置けるところならどこでも動きます。

## oVice への登録

[カスタムオブジェクトの作成（公式ヘルプ）](https://help.ovice.com/hc/ja/articles/26847715603225)の手順で登録します。組織オーナー（または権限のあるグループ）の操作が必要です。

1. スペースヘッダーの三本線 → 「組織」タブ → 組織の設定 → 外部サービス連携 → 「カスタムオブジェクト」
2. 「新規作成」で次のように設定して保存
   - オブジェクト名：`oVice Racing` など
   - 種別：**スペースオブジェクト**（スペースに常設する場合）または クイックオブジェクト
   - オブジェクト URL：公開した URL（例 `https://<ユーザー名>.github.io/<リポジトリ名>/`）
   - メールアドレスの取得：オフのままで OK
3. スペースオブジェクトの場合は「スペースをカスタマイズ」で好きな位置に設置

遊び方：誰か 1 人が「パーティーを作る」を押し、表示されたコードをボイスチャットやチャットで伝えます。ほかの人はコード欄に入力して「参加」（oVice の中継が届いていれば、一覧の「参加」ボタンでも入れます）。メンバーがそろったらホストが「レース開始」を押します。

オブジェクトの範囲から出て画面が閉じると、その人はパーティーから抜けます。ホストが抜けるとパーティーは解散します。

## 調整できること

- 送信頻度：URL に `?hz=15` のように付けると走行中の位置送信回数（毎秒、既定 10）を変更できます。人数が多くて重い場合は下げてください。
- コース：`js/track.js` の `CONTROL`（通過点の座標）を書き換えるとコース形状が変わります。
- 車の性能：`js/game.js` の `PHYS`。

## 仕組みと制限

- 各プレイヤーは自分の車を自分の画面で動かし、位置を 1 秒に約 10 回ホストへ送ります。ホストはそれを他のメンバーへ中継します。他人の車は受信した位置から少し先を予測して滑らかに表示します。
- パーティーの接続には WebRTC（ブラウザ同士の直接通信）を使います。社内ネットワークなどで外部への直接通信が厳しく制限されていると、つながらない場合があります。
- 接続相手を見つけるために PeerJS の無料公開サーバー（0.peerjs.com）を使っています。そこで扱うのはパーティーコードと接続情報だけで、ゲームの中身は送りません。
- 車同士の衝突判定はありません（通信遅延で不公平にならないように）。
- タイムは各自の画面で「GO!」からゴールまでを計測します。スタート合図の届く時間差（通常 0.1 秒前後）の分だけ誤差があります。
- 1 パーティー最大 8 人です。
- oVice 側の通信 API は公式サンプル（[oviceinc/custom-plugins](https://github.com/oviceinc/custom-plugins)）の仕様に沿っています。実際の oVice スペースでの動作確認はまだ行っていません。
